# Palantir 本体论学习：30 天 FDE 实践课程

本项目将 Palantir Ontology、真实 FDE 能力和可落地的小型方案设计结合。每课约 20 分钟：读概念、看案例、完成一个可复用产物。

## 目录

- `days/Day-01.md`–`Day-05.md`：问题、对象、属性、链接、动作
- `days/Day-06.md`–`Day-10.md`：数据映射、主键、质量、血缘、指标
- `days/Day-11.md`–`Day-15.md`：Object View、Workshop、Functions、MVP
- `days/Day-16.md`–`Day-20.md`：客户发现、迭代、协作、权限、审计
- `days/Day-21.md`–`Day-30.md`：AIP、行业案例、方案、作品集与综合演练

资料与岗位口径见 [sources.md](sources.md)。所有未标注“公开案例”的行业设计都是教学推演。
