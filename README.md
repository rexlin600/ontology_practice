# Palantir 本体论学习：30 天 FDE 实践课程

这不是链接合集，而是一套可以直接阅读和动手完成的讲义。每课约 20–30 分钟，以“医院胸痛协同”贯穿基础概念，再迁移到器械、制造、供应链和金融场景。

## 如何使用

1. 先读“把它放进真实现场”，建立直觉；
2. 复画 Mermaid 图，确认对象、关系和动作；
3. 完成练习，再用参考答案检查；
4. 将 Day 30 的综合练习整理成作品集案例。

## 路线

| 阶段 | 日课 | 你将产出的东西 |
| --- | --- | --- |
| 从现实到对象 | Day 01–06 | 决策画布、对象/关系模型、Action 设计 |
| 从数据到可信结论 | Day 07–10 | 映射、指标、质量规则和血缘 |
| 从模型到一线工作 | Day 11–15 | 角色视图、函数、MVP 与反馈记录 |
| 从试用到可治理交付 | Day 16–20 | 访谈、迭代、流程、协同、权限 |
| 从 AI 到行业方案 | Day 21–30 | AI 护栏、行业案例、实施方案与作品集 |

> 医疗案例为教学推演，不构成临床决策支持方案；正式使用须经本地临床、信息安全、合规与质量流程验证。
